# Consistency Ledger — quick guide

## Open and use it

1. Open `index.html` in a current browser such as Chrome, Edge, or Firefox. The app is a single file; it does not need an install or an account.
2. Enter the account size, the consistency percentage, the profit target percentage, and the evaluation period.
3. After each trading day, choose **Add trading day** and enter that day's net profit or loss in USD. Use a minus sign for a loss. Leave a day blank until you know its result.
4. Read the status, performance cards, chart, and daily log. Use the theme button to switch between light and dark mode.

## Example

For a `$50,000` account with an `8%` target and a `30%` consistency rule:

- Profit target: `$4,000`
- Maximum profit in one day under this calculator's formula: `$1,200`
- Minimum days to spread the target across: `4`

The calculator uses **consistency percentage × profit target** for the daily cap. Some firms define consistency using total profit or another formula, so match the inputs and calculation to the exact rules for your challenge.

## Save and share

- Entries save in the browser on the current device when browser storage is available.
- Select **Export backup** to download a JSON copy of the setup and trading days. Select **Import backup** on another browser to restore it.
- **Reset ledger** clears the current browser's saved entries after asking you to confirm.
- To share the tool, send `index.html` (or the included shareable ZIP). To share your ledger data as well, send the exported JSON backup separately.

## Hinglish quick guide

1. `index.html` ko Chrome, Edge, ya Firefox mein kholo. Install ya account ki zaroorat nahi.
2. Account size, consistency %, profit target %, aur evaluation days bharo.
3. Har trading day ke baad **Add trading day** dabao aur net P/L USD mein likho. Loss ke liye minus sign lagao.
4. Status, chart, aur daily log dekho. Data isi browser/device mein save hota hai. Doosre device par le jaane ke liye **Export backup** karke JSON file ko **Import backup** karo.
5. App share karne ke liye `index.html` ya ZIP bhejo. Apna trading data share karna ho to backup JSON alag se bhejo.

Yeh ledger tracking ke liye hai. Apni prop firm ke exact consistency rules aur numbers zaroor verify karo.
